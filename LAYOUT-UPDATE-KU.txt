ڕێکخستنی نوێی Alo Solar Energy

فایلەکانی ناو ZIP لە ڕەگی پرۆژەی وێبسایتەکەت دابنێ، نەک خودی ZIP.
لە GitHub فایلەکان جێگۆڕکێ بکە و Commit changes بکە، پاشان چاوەڕێی Cloudflare Deployment بە.

گۆڕانکاری: فۆنت و بۆشاییەکان، ڕێکخستنی مۆبایل، کارتەکان، خانەکانی خۆتۆمارکردن و ئادمین، مێنیوی ئادمین لە مۆبایل.
دیزاینی سەرەکی EV Charge پارێزراوە؛ تەنها خوێنرایی و خانەکان ڕێکخراون.
کۆدەکانی حیسابکردن، نرخ، API و داتابەیس نەگۆڕدراون.

ئەمە نوێکردنەوەی وێبسایتە؛ APK یان IPA نییە. ئەپی مۆبایل هێشتا پێویستی بە build و تاقیکردنەوەی ئامێر هەیە.
بۆ گەڕانەوەی دیزاین: تەنها لینکی layout-refined.css لە کۆتایی پێنج لاپەڕەکە بسڕەوە.
