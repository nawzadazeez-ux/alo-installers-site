ڕێنمایی گۆڕینی نرخەکان
======================

١. فایلی prices.js بکەرەوە.
٢. نرخەکە لە دوای price: بگۆڕە.
   نموونە: price: 108 بگۆڕە بۆ price: 110
٣. فایلەکە Save بکە.
٤. prices.js و index.html هەردووکیان لە Cloudflare دابنێ.

زیادکردنی بابەتی نوێ
--------------------
لە بەشی panels یان batteries یان inverters، یەک ڕیزی تەواوی
{ ... } کۆپی بکە، لە ژێر ڕیزی کۆن دایبنێ و زانیارییەکانی بگۆڕە.

گرنگ:
- id ـی هەر بابەتێک دەبێت جیاواز بێت.
- کۆما (,) لە نێوان بابەتەکان مەسڕەوە.
- ناوی prices.js مەگۆڕە، چونکە index.html بەو ناوە دەیخوێنێتەوە.
- نرخەکان بە دۆلاری ئەمریکییە.
